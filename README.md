A small proof-of-concept endless platformer game I made in Godot for the "Atestat de Informatica" in 2025. Levels are actually pretty hard because I thought they were too easy when I was initially playtesting, but it's actually pretty damn difficult.

Includes random screens selected from a pool, a short text-based tutorial, a timer to encourage you to actually go fast, health and timer pickups, and some pretty smooth movement, with slide-canceling to retain dash momentum.
